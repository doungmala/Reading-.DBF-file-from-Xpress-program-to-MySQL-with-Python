# Reading-.DBF-file-from-Xpress-program-to-MySQL-with-Python

ส่วนที่ 1: การนำเข้าไลบรารี (Libraries)

<img width="1082" height="217" alt="image" src="https://github.com/user-attachments/assets/f5251af6-f012-45d9-8470-dd61667d2f8f" />

- บรรทัด import glob: นำเข้าโมดูลสำหรับค้นหาไฟล์ที่มีชื่อเข้ากับรูปแบบแพทเทิร์น (เช่น ใช้หาไฟล์ทั้งหมดที่ลงท้ายด้วย .dbf)

- บรรทัด import os: นำเข้าโมดูลจัดการเกี่ยวกับระบบปฏิบัติการ เช่น การสร้างโฟลเดอร์ หรือจัดการเส้นทางไฟล์

- บรรทัด import sys: นำเข้าโมดูลจัดการตัวแปรและพารามิเตอร์ที่รับเข้ามาทาง Command Line (เช่น รับค่าคำสั่ง csv หรือ mysql)

- บรรทัดดาวน์โหลด from dbfread import DBF: ดึงคลาส DBF จากไลบรารี dbfread มาใช้สำหรับเปิดและอ่านไฟล์ฐานข้อมูล DBF

- บรรทัด import mysql.connector: นำเข้าไลบรารีเชื่อมต่อฐานข้อมูล MySQL ของทางการเพื่อสั่งรันคำสั่ง SQL ต่างๆ
  

ส่วนที่ 2: การตั้งค่าระบบ (Configuration)

<img width="1082" height="300" alt="image" src="https://github.com/user-attachments/assets/a998906c-98b2-434d-826b-2a8e86385c61" />

- บล็อก MYSQL_CONFIG: ประกาศตัวแปรเก็บค่าคอนฟิกูเรชันสำหรับการเชื่อมต่อ MySQL (โฮสต์, พอร์ต, ชื่อผู้ใช้, รหัสผ่าน และชื่อฐานข้อมูล)

- บรรทัด DBF_ENCODING = "tis620": กำหนดรหัสภาษาเป็น tis620 (หรือ cp874) เพื่อให้โปรแกรมอ่านตัวอักษรภาษาไทยจากไฟล์ DBF ได้อย่างถูกต้อง ไม่เป็นอักษรต่างดาว
  

ส่วนที่ 3: ฟังก์ชันเสริมสำหรับจัดการข้อมูล (Helper Functions)

- บรรทัด def safe_value(v):: ประกาศฟังก์ชันแปลงค่าข้อมูล v ให้มีความปลอดภัยก่อนนำไปบันทึก
  
- บรรทัด if v is None: return None: ถ้าค่าเป็นค่าว่าง (Null) ให้คืนค่าเป็น None ตามเดิม
  
- บรรทัด if hasattr(v, "isoformat"): return v.isoformat(): ถ้าข้อมูลนั้นเป็นประเภทวันที่ (Date) ให้แปลงเป็นข้อความมาตรฐานรูปแบบมาตรฐานสากล (ISO format)
  
- บรรทัด if isinstance(v, bytes):: ตรวจสอบว่าข้อมูลมาในรูปแบบไบต์ (Binary) หรือไม่
  
- บรรทัดภายใน try/except: พยายามถอดรหัสไบต์นั้นด้วย encoding tis620 หากเกิดข้อผิดพลาดจะบังคับข้าม (errors='ignore') ด้วย utf-8 แทน

- บรรทัด def mysql_type(dbf_field_type):: ฟังก์ชันแปลงชนิดข้อมูลจากโครงสร้าง DBF ให้เข้ากับโครงสร้างของ MySQL
  
- เงื่อนไข C (Character) และ M (Memo): แปลงเป็นชนิด TEXT ใน MySQL
  
- เงื่อนไข N (Numeric) และ F (Float): แปลงเป็นชนิดตัวเลขทศนิยม DOUBLE
  
- เงื่อนไข L (Logical): แปลงเป็นชนิดค่าความจริง BOOLEAN
  
- เงื่อนไข D (Date): แปลงเป็นชนิดวันที่ DATE
  
- กรณีอื่นๆ: หากไม่ตรงกับเงื่อนไขใดเลย ให้กำหนดเป็น TEXT ป้องกันข้อผิดพลาด

<img width="1066" height="266" alt="image" src="https://github.com/user-attachments/assets/ada839c1-45d8-4761-ba4a-70e081eaa4e6" />

- บรรทัด def read_dbf(filepath):: ฟังก์ชันกลางใช้เปิดไฟล์ DBF ตามที่ระบุในเส้นทาง filepath

- บล็อก try...except: ป้องกันโปรแกรมพัง (Crash) กรณีไฟล์เสียหาย หาไฟล์ไม่เจอ หรืออ่านไม่ออก โดยจะพิมพ์ข้อความเตือนและคืนค่า None แทน


ส่วนที่ 4: โหมดส่งออกเป็น CSV (export_all_to_csv)

<img width="1066" height="290" alt="image" src="https://github.com/user-attachments/assets/8eaa0c5a-e146-4d73-a1e6-fe22a0ce2992" />

- กำหนดชื่อโฟลเดอร์ปลายทางชื่อ csv_export และตรวจสอบว่ามีหรือยัง หากยังไม่มีให้สร้างขึ้นมาใหม่ด้วยคำสั่ง os.makedirs
  
- ค้นหาไฟล์ .DBF ทั้งหมดในโฟลเดอร์ปัจจุบันเก็บไว้ในตัวแปรลิสต์ dbf_files หากไม่พบไฟล์ จะแสดงข้อความแจ้งแล้วจบการทำงานทันที

<img width="1066" height="256" alt="image" src="https://github.com/user-attachments/assets/3128a745-ac8d-4c74-99f7-a7af87b32b04" />

- วนลูปหยิบไฟล์ DBF ทีละไฟล์มาประมวลผล ตัดนามสกุล .dbf ออกเพื่อให้ได้ชื่อตั้งต้นสำหรับทำชื่อไฟล์ CSV
  
- เรียกใช้ฟังก์ชัน read_dbf เพื่อโหลดข้อมูลในไฟล์นั้นขึ้นมาเก็บไว้
  
- สร้างเส้นทางไฟล์ CSV ปลายทาง
  
- เปิดไฟล์ในโหมดเขียน (w) พร้อมกำหนด encoding เป็น utf-8-sig (เพื่อให้เปิดใน Excel แล้วภาษาไทยไม่เป็นภาษาต่างดาว)
  
- ดึงชื่อฟิลด์มาทำเป็นหัวตาราง (Header) และวนลูปทำความสะอาดข้อมูลทีละเรคคอร์ดด้วย safe_value ก่อนเขียนลงไฟล์ CSV
  

ส่วนที่ 5: โหมดนำเข้า MySQL (import_all_to_mysql)

<img width="1066" height="256" alt="image" src="https://github.com/user-attachments/assets/89b167ae-aa2d-4a70-8bc6-01e1e1a13cea" />

ค้นหาไฟล์ DBF และทำการเชื่อมต่อเข้าสู่ฐานข้อมูล MySQL ผ่าน mysql.connector.connect โดยดึงค่าจากพจนานุกรม MYSQL_CONFIG หากเชื่อมต่อไม่ได้จะแสดง Error แล้วหยุดการทำงาน

<img width="1066" height="256" alt="image" src="https://github.com/user-attachments/assets/09a23b73-d3f2-43b1-89e4-48c3d7037178" />

- วนลูปจัดการไฟล์ DBF ทีละไฟล์ แปลงชื่อตารางให้เป็นตัวพิมพ์เล็กทั้งหมดเพื่อป้องกันปัญหาความไม่เข้ากันของชื่อตารางในระบบ MySQL
  
- ดึงโครงสร้างฟิลด์ทั้งหมดมาแปลงเป็นคำสั่ง SQL ประเภท CREATE TABLE โดยจับคู่ชื่อคอลัมน์กับชนิดข้อมูลผ่านฟังก์ชัน mysql_type
  
- สั่งลบตารางเก่าทิ้งหากมีชื่อซ้ำ (DROP TABLE IF EXISTS) แล้วรันคำสั่งสร้างตารางใหม่
  
- เตรียมชุดคำสั่ง INSERT INTO แบบเตรียมตัวแปรพารามิเตอร์ (%s) เพื่อความปลอดภัยและรวดเร็ว
  
- วนลูปดึงข้อมูลใน DBF ทีละเรคคอร์ด มาทำความสะอาดค่าด้วย safe_value แล้วเก็บสะสมใส่ก้อนข้อมูลชุดละ 1,000 แถว (batch_data)
  
- เมื่อสะสมครบ 1,000 แถว จะทำการส่งข้อมูลชุดใหญ่ครั้งเดียวด้วย executemany และบันทึกข้อมูลลงฐานข้อมูล (conn.commit()) เพื่อช่วยเร่งความเร็วในการประมวลผล
  
- เมื่อจบกระบวนการทั้งหมด จะทำการปิดการเชื่อมต่อ Cursor และ Database Connection เพื่อคืนทรัพยากรระบบ
  

ส่วนที่ 6: จุดเริ่มต้นการทำงาน (Main Entry Point)

- บรรทัด if __name__ == "__main__": เช็คว่าสคริปต์นี้ถูกเรียกใช้งานโดยตรงจาก Command Line หรือไม่
  
- ตรวจสอบจำนวนอาร์กิวเมนต์ที่ป้อนเข้ามา หากพิมพ์มาแคชื่อไฟล์เฉยๆ จะแสดงคู่มือการใช้งานเบื้องต้น
  
- หากผู้ใช้พิมพ์พารามิเตอร์ต่อท้าย เช่นพิมพ์ csv โปรแกรมจะเรียกฟังก์ชัน export_all_to_csv() แต่ถ้าพิมพ์ mysql จะเรียกฟังก์ชัน import_all_to_mysql() ให้ทำงานตามที่เลือกครับ
